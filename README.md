**项目名称**: 一种基于AppleWatch的短时间睡眠监测的方法	（独立开发者）  
**项目时间**: 2021.07-2022.07

#### 项目简介
该项目基于Apple Watch的实时心率数据来识别用户的睡眠深度，在进入深度睡眠之前唤醒用户。项目基于一个倒计时应用程序，在倒计时的同时收集用户的心率数据，并估算此时的睡眠阶段。

#### 个人工作
1. **数据处理**：利用AppleWatch实时心率计算心跳间隔，并构建心电洛伦兹图。
2. **唤醒算法**：通过图上点的分布中心和变化范围评估睡眠深度，确定最佳唤醒时间。
3. **项目实践**：使用Swift语言在watchOS平台上实现实时数据处理和用户唤醒功能。根据50名受试者共计100次的实验结果，验证该方法在睡眠深度识别及唤醒的有效性。

#### 项目难点
1. **数据准确性**：由于Apple Watch只能提供30秒的心电图记录，如何有效利用5秒心率数据估算RRI成为关键。
   - 解决方法：采用平均RRI作为近似值，利用连续数据段进行评估。
2. **睡眠阶段估算**：准确区分不同睡眠阶段是应用的核心难点。
   - 解决方法：参考现有研究，通过Lorenz图的变化趋势和椭圆面积的稳定性评估睡眠深度。
